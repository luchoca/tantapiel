# Tanta Piel

Landing page en React + Vite, inspirada en la estructura editorial/minimalista de la referencia indicada, con identidad y fotografías distintas.

## Ejecutar

```bash
npm install
npm run dev
```

Luego abrir la URL que indique Vite (normalmente http://localhost:5173).

## Producción

```bash
npm run build
npm run preview
```

### Personalización rápida
- Editá `src/main.jsx` para textos, email y datos.
- Editá `src/styles.css` para colores, tamaños y espaciados.
- Las fotos actuales son externas (Unsplash); si querés alojarlas localmente, reemplazá las URLs por archivos dentro de `public/`.
